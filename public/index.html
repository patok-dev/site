patok

Autonomous build loop driving agent CLIs.

Install

macOS (arm64, x86_64) and Linux (x86_64).

curl -fsSL https://patok.dev/install.sh | sh

The script downloads the latest release, verifies its SHA-256 against the release checksums, and installs patok to ~/.local/bin. Make sure that directory is on your PATH. Read the script first if you like.

Uninstall

Removes the binary and the per-user data directory:

curl -fsSL https://patok.dev/install.sh | sh -s -- --clean
